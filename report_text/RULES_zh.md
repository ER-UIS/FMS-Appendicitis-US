# 报告原文特征提取标注规则（v1（2026-10-11））
Annotation rules (Chinese) applied when the report text of the 593 expert-read patients was coded feature by feature; `report_text_extract.py` pre-fills each feature from the text with these rules and one author verified every entry (Methods, Report-text feature extraction).

## 一、目的
- 从超声报告原文（"描述"）中只依据文字提取九项特征，作为"真实常规报告"，与 FMO 在同一专家盲审参照下比较。
- 对象：专家组 A 队列 300 例与专家组 B 队列 321 例，合并去重共 593 例。

## 二、盲法
- 标注者只看报告文字，不看图像、病理、化验、临床资料、报告标签、FMO 输出或专家组结果。
- 标注者最好不是专家组 A、B 的阅片者；核对表已按随机顺序排列，请按序号顺序完成。
- 全部完成并签名之前，不要查看任何专家结果或模型结果。

## 三、阅读范围
- 阑尾相关段落：报告中含"阑尾、右下腹、麦氏、回盲、同心圆"的行；核对表"阑尾相关段落"列已摘出，必要时查看"报告全文"页。
- 腹腔积液看全文（含盆腔、肠间隙、肝肾间隙、脾肾间隙等）。
- 描述淋巴结的句子、其他脏器（肝、胆、脾、胰、肾、膀胱、子宫附件、前列腺等）的描述一律不计。

## 四、判定原则
1. 每项记三种之一：阳性（文字明确描述该异常）、阴性（文字明确否定）、未提及（文字未涉及）。统计时"阴性"与"未提及"合并为阴性。

2. 只按字面判定，不推断。例如写"肿胀增粗的阑尾"但未提系膜，系膜记"未提及"；不能因为是阑尾炎就推断其他特征。

3. 含"可疑、疑似、考虑、不除外、似"等措辞而描述了该异常的，记阳性，并在备注写"措辞不确定"。

4. 同一特征阳性与否定语句并存：以针对阑尾或阑尾区病灶的具体描述为准。腹腔积液：任一部位描述游离积液即记阳性，即使另有"腹膜腔内未探及游离液性暗区"。血流：阑尾或病灶处"可见/探及血流"即记阳性，即使另有"腹腔内未见异常彩流"。

5. 模板句"CDFI：腹腔内未见异常彩流/血流信号"：血流记阴性（明确否定）。

6. 报告写"阑尾未显示、显示不清"的，外径等阑尾本身特征记"未提及"，并在备注写明。


## 五、各特征判定要点
- 外径测量值——"外径测量值(mm)·人工"列记录报告中写明的阑尾外径数值（毫米）。同一报告写了多个外径（如远段 18 mm、根部 4.3 mm）取最大值；只写病灶大小（如"低回声区 25×9 mm"）或壁厚的不填；报告未写外径则留空。已预填程序提取值，请逐例核对。"年龄(岁)"列已按病例资料预填；外径为 6.0–6.9 mm 的病例以黄色标出，判定时须结合年龄。
- 阑尾外径（AODC）——阳性：写"肿胀增粗的阑尾、阑尾肿胀、肿大的阑尾"，或外径 ≥7 mm；年龄 <18 岁者外径 ≥6 mm。阴性：外径 <6 mm，或写"未见（明显）肿胀"。外径 6.0–6.9 mm 且未写是否肿胀：按"年龄(岁)"列判定（<18 岁为阳性，≥18 岁为阴性）。文字明确否定时以文字为准：外径达到阳性阈值（含 <18 岁 6.0–6.9 mm），但报告写"未见（明显）肿胀"且指的就是该阑尾，记阴性（报告医师已作出判断）；若否定语句指的是另一段阑尾（如"近段未见异常"），以描述病变段的语句为准。右下腹或阑尾区包块、低回声区只给大小（如 25×9 mm）：若文字表明是阑尾（条状、管状、一端为盲端），按短径判定（≥7 mm 阳性）；不能判断为阑尾的记"未提及"并备注。
- 粪石（CC）——阳性：写"粪石"，或阑尾腔内/阑尾区病灶内"强回声团、强光团"（伴或不伴声影）。阴性：写"未见粪石"。点状或气体样强回声属积气，不计入粪石。
- 腹腔积液（CAE）——阳性：腹腔、盆腔、肠间隙、肝肾/脾肾间隙等游离液性暗区，或写"腹腔积液、盆腔积液"。阴性：写"腹膜腔内未探及游离液性暗区、未见腹腔积液"。阑尾周围局限积液或脓肿不计入（属阑尾周边积液）。
- 阑尾壁情况（AWC）——阳性：阑尾壁"连续性中断、不连续、分层消失或不清、层次不清、毛糙、模糊、缺损、穿孔"。阴性：写"壁连续、光滑、层次清晰"。只写壁厚数值的记"未提及"（本特征定义为分层消失或中断，不按厚度判定）。回盲部肠壁的描述不计。
- 阑尾腔内积气（GAC）——阳性：阑尾腔内或壁内"积气、气体样强回声"。阴性：写"腔内未见积气"。肠道积气、消化道积气不计。
- 阑尾腔内积液（FAC）——阳性：写"腔内积液、腔内液性暗区、管腔扩张积液"，或阑尾/阑尾区病灶"内透声差、欠佳"。阴性：写"腔内未见积液、管腔萎瘪"。单写"张力高"不计。腹膜腔、盆腔的描述不计。
- 阑尾周边积液（PFCC）——阳性：阑尾"周边、周围"积液、液性暗区、渗出或脓肿。阴性：写"周边未见液暗区、周围未见积液"。
- 阑尾周围系膜（MSC）——阳性：阑尾"周边/周围系膜肿胀、增厚、回声增强"，或"网膜包裹"。阴性：写"系膜未见肿胀"。系膜淋巴结、回盲部肠壁肿胀不计。
- 阑尾区血流（BFC）——阳性：阑尾壁、阑尾内或阑尾区病灶"可见、探及血流（彩流）信号"，或"血流丰富、增多"。阴性：写"未见（异常）血流/彩流"（含模板句）。其他脏器、淋巴结的血流不计。

## 六、核对流程
1. 逐例阅读"阑尾相关段落"，必要时查看"报告全文"页（按序号对应）。

2. 先核对"外径测量值"与"年龄"列，再核对九项特征。每项特征有三列：程序结果、依据（程序匹配到的原文片段）、人工判定。人工判定已预填程序结果；同意不改，不同意改为正确值（下拉选择：阳性、阴性、未提及）。

3. 程序结果为"待核对"的项，人工判定为空（黄色），必须填写，并在备注写依据。

4. 不要只看"依据"列：程序可能漏掉写在别处的描述，请通读段落。

5. 每例完成后在"核对人"和"日期"列签名；"修改数"列自动统计与程序不一致的项数。


## 七、质量控制
1. 第二名标注者独立完成随机 10%（约 60 例，使用另一份未预填的核对表），计算与第一名标注者的一致性（Cohen κ）；分歧由第三人裁定。

2. 记录每位标注者的总用时。

3. 规则如需修改，须在开始标注前定稿；标注过程中发现规则未覆盖的情况，在备注中记录，统一讨论后再定。


## 八、程序说明
- 预提取程序 report_text_extract.py（随核对表提供）按本规则用关键词和否定词逐句判定，只读取申请号与"描述"两列。程序结果仅为辅助，最终以人工判定为准；论文方法部分将写明"程序预提取、人工逐条核对"。
